Based on the **Stroop Effect** brain training phenomenon: Match the **font color** of the text, NOT the word itself!

---

## 📱 Features Included (According to GDD)

1. **3 Game Modes**:
   - ⏱️ **Time Attack**: 60-second countdown. Every 10 correct answers awards a **+3s bonus**.
   - ❤️ **Lives Mode**: 3 hearts. Speed increases dynamically across 5 difficulty tiers (from 3.0s down to 1.0s) and color button choices scale from 3 to 6 colors!
   - ⚡ **Speed Rush**: 30-second blitz mode with 6 tricky close shade buttons (e.g., Light Blue vs Dark Blue, Lime vs Forest Green).
2. **Scoring & Streak Bonuses**:
   - Base correct answer: **+10 pts**
   - Streak x3: **+5 bonus**
   - Streak x5: **+15 bonus**
   - Streak x10: **+50 bonus**
   - Wrong answer: **-5 pts** (Time Attack) or **-1 Life** (Lives Mode).
3. **Audio & Tactile Engine**:
   - Built with the procedural Web Audio API (100% zero external audio file dependencies, instant zero-latency playback).
   - Audio synthesized for clicks, correct chimes, wrong buzzers, countdown ticks, bonus fanfares, and ambient synth BGM.
   - Haptic vibration feedback for mobile devices.
4. **Full AdMob Monetization Architecture**:
   - Sticky bottom **Banner Ad (320x50)**.
   - **Interstitial Ad**: Frequency-capped to max 1 per 90 seconds, shows on every 2nd game over, never on the 1st game.
   - **Rewarded Video Ad**: 
     - Lives Mode: Watch Ad = +1 Extra Life (Max 2 per game)
     - Time Attack: Watch Ad = +15 Seconds (Max 1 per game)
     - Result Screen: Watch Ad = Double Score (1 per game)
5. **Local Data Persistence**:
   - Saves high scores for all 3 modes, total games played, total correct answers, accuracy percentage, and sound/vibration toggles.
6. **Social & Sharing**:
   - Score sharing using native Android Web Share API (`navigator.share`) or automatic clipboard copy fallback.

## 📦 How to Build the Android APK

You have three streamlined options to generate the APK:

### Option A: Local Build via Android Studio & Capacitor
If you have Android Studio installed:
1. Open PowerShell in `d:\projects\color-match`:
   ```bash
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android
   ```
2. In Android Studio:
   - Click **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
   - Your installable APK will be generated at:
     `android/app/build/outputs/apk/debug/app-debug.apk`

---

### Option B: 100% Automated Free Cloud Build (GitHub Actions)
If you don't have Android Studio or Java installed locally, a turnkey GitHub Actions workflow is already pre-configured in `.github/workflows/build-apk.yml`:
1. Push this project to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Color Match APK"
   git remote add origin https://github.com/YOUR_USERNAME/color-match.git
   git push -u origin main
   ```
2. Go to your GitHub repository > **Actions** tab.
3. The **Build Color Match Android APK** workflow will automatically compile the APK in the cloud using Google's official Android SDK & Gradle.
4. Download the compiled `ColorMatch-Debug-APK` directly from the workflow run!

---

### Option C: Online 1-Click APK via PWABuilder
1. Deploy or host the `src` folder (e.g. on Vercel, Netlify, or GitHub Pages).
2. Go to [https://www.pwabuilder.com](https://www.pwabuilder.com)
3. Enter your URL and click **Package for Android (APK / TWA)**.
4. Download the generated ready-to-install signed APK!
